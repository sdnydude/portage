## Learnings

- A proof on a forced fixture is not a proof. Category chips "passed" on a
  planted row while 151 of 156 real items were unreachable.
- Markdown tables corrupt regex specs: `\|` survives copy-paste into YAML as
  a literal pipe and passes syntax checks. Specs carry patterns in code
  blocks only.
- Loki `retention_period` is decorative without `compactor.retention_enabled`
  on boltdb-shipper — measure the chunk store, don't read the config.
- Mocked drizzle tests cannot see SQL rendering; only the live run caught
  `($1, $2)::text[]`.
- The CI-replica Docusaurus build lives in aifactory docs-site, not in
  portage/website (no package.json there).

## Insights

- Ship-log identity by `registry_id` (registry_id → pr_url → exact title →
  unique slug, ambiguous fails loud) is what makes regeneration safe.
- A deploy pipeline that can fail silently needs a drill, not a promise:
  `gh workflow run deploy-docs.yml -f drill=true` proved the alarm.
- Redaction at ingest is directive-compatible (masks new lines, deletes
  nothing); stored history is the operator's alone.
